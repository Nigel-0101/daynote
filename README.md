# 日序 Daynote

为剪辑师准备的个人日常规划与项目工作空间。

## 功能

- 项目总览、参与人员与分工、开始日期和交付日期。
- 项目进度及更新历史，未完成项目自动前移、完成项目自动后移。
- 工作日志：记录谁在什么时间做了什么，自动计算时长。
- 项目日历、每日计划、本周安排、剪辑阶段模板。
- 专注计时、习惯打卡、心情和日常小记。
- JSON 备份导出和恢复。
- 项目归档和恢复，卡片内直接管理制作任务。
- A-copy、B-copy 到 Z-copy、AA-copy 的项目独立版本顺序。
- 上下班、加班时长、调休余额和出勤估算，跨午夜工作与次日整点建议。
- 日历上的加班、调休、节假日与补班标记，个人资料合并导入。
- 自托管思源黑体，全站统一齐线等宽数字。

## 使用

连接后的设备直接打开 https://nigel9.cn/ 即可使用，无需登录或保持电脑开机。

个人记录通过云端服务保存到独立的 GitHub 私有仓库。公开网站只包含界面代码和字体，不包含个人资料或密钥。浏览器仅保存随机设备识别凭证，不保存项目或考勤记录；旧版副本不会被主动清除。云端保留失败保存的恢复副本和 GitHub 版本历史；失败或发生版本冲突时会明确提示。

新浏览器或清除设备凭证后需要站点所有者连接该设备。仅知道网址无法读取或修改个人记录。单独下载网页不能写入 GitHub。

新建、编辑项目后保持当前页面；分辨率、帧率、成片时长和备注可以留空。任务用开始、结束时间确定时长。计划支持一周、半个月、整月范围，拖动改期与撤销。

详细说明见 [使用说明](使用说明.md)。

## GitHub Pages

网页界面由 GitHub Pages 托管，保存功能由独立云端服务提供。在仓库 Settings → Pages 选择 **Deploy from a branch**，使用 **main / (root)** 发布即可。根目录的 `.nojekyll` 用于直接发布静态文件。

## 本地预览

安装 Node.js 后运行：

```sh
node server.cjs
```

打开 <http://127.0.0.1:4380/>。此命令仅预览界面；正式保存服务在云端运行。
