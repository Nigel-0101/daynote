# 日序 Daynote

为剪辑师准备的个人日常规划与项目工作空间。

## 功能

- 项目总览、参与人员与分工、开始日期和交付日期。
- 项目进度及更新历史，未完成项目自动前移、完成项目自动后移。
- 工作日志：记录谁在什么时间做了什么，自动计算时长。
- 项目日历、每日计划、本周安排、剪辑阶段模板。
- 专注计时、习惯打卡、心情和日常小记。
- JSON 备份导出和恢复。

## 使用

网站无需注册。也可以下载 `index.html`，直接用浏览器打开。

所有记录只保存在当前浏览器，不会上传到 GitHub，不支持跨设备同步或多人在线协作。请定期通过「数据与备份」导出记录。更换网址或浏览器时，需要在原地址导出备份，再到新地址导入。

详细说明见 [使用说明](使用说明.md)。

## GitHub Pages

这是没有外部依赖的静态网站。在仓库 Settings → Pages 选择 **Deploy from a branch**，使用 **main / (root)** 发布即可。根目录的 `.nojekyll` 用于直接发布静态文件。

## 本地预览

安装 Node.js 后运行：

```sh
node server.cjs
```

打开 <http://127.0.0.1:4380/>。
